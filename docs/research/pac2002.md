# PAC2002 (MSC Adams/Tire): equations and decisions

Revision 4. Primary source: MSC. The equations were transcribed in rev 2 from the MSC page images and text layer (REV2 pac2002.md sections 2-10). Rev 4 re-verified (18), (23), (30), (46), (52), (78)-(88), the friction ellipse, (100)-(103) and pp.23-24 and 31-32 visually.

## 1. Scope

- MSC p.2: 'backward compatible with all previous versions of PAC2002, MF-Tyre 5.x tire models, and related tire property files'.
- Steady state only. Transient eqs (89)-(99) are out of scope; (94) carries the printed typo kappa' = (u1/sigma_x)*sin(Vx).
- All turn-slip factors zeta_0..zeta_8 = 1, so C_r = zeta_7 = 1 [derived].

## 2. Evaluation order (authoritative)

```
 0  load: FNOMIN and UNLOADED_RADIUS > 0, LFZO > 0, kernel-critical keys present
    (tir-format.md section 3); choose the combined method (D-07)
 1  Fz <= 0 -> all outputs 0                                D-04
 2  clamp Fz, kappa, alpha, gamma to [*_RANGE]              D-03
 3  F'z0, dfz                                               (16)
 4  Fx0                                                     (18)-(28)
 5  Fy0, Ky                                                 (30)-(41)
 6  pure t(alpha_t), Mzr(alpha_r); Mz0 = -t*Fy0 + Mzr       (43)-(56)
 7  combined Fx, Fy: cosine (58)-(77) or friction ellipse (section 5.4)
 8  combined Mz                                             (78)-(85); D-05, D-09, D-16, D-24
 9  Mx (86); My (87) or (88)                                D-11
10  Mz_gyr = 0 (D-20); output sign mapping (conventions.md section 4)
Uncombined mode (D-26): Fx = Fx0, Fy = Fy0, Mz = Mz0; Mx and My use these forces.
```

gamma is the raw input. Epsilon guards per conventions.md section 7.

## 5. Decision details

### 5.1 Moment arm s (D-09)

MSC gives no equation for s. It gives only:
- p.17: 's: Moment at combined slip'.
- p.19: LS, 'Scale factor of moment arm of Fx'.
- p.32: SSZ1 'Nominal value of s/R0: effect of Fx on Mz'; SSZ2 'Variation of distance s/R0 with Fy/Fznom'; SSZ3 '... with inclination'; SSZ4 '... with load and inclination'.

Implementations agree on the structure R0*(SSZ1 + SSZ2*Fy/N + (SSZ3 + SSZ4*dfz)*g)*LS, with Fy the combined output. They differ on N and g:

| Implementation | N | g |
|---|---|---|
| MFEVAL :1583 (paper A56, 'better correlation with TNO'; book 4.E76 with F'z0 is commented out at :1570) | FNOMIN | raw gamma |
| OPENTIRE :423 | FNOMIN*LFZO | sin(gamma) |
| CHRONO :313-315 | F'z0 | raw gamma (never set) |
| CHRONO8 :1231-1233 | FNOMIN | sin(gamma) |
| TEASIT Mz.m:24 (MF 6.1) | F'z0 | sin(gamma), at gamma = 0 |

Choice N = FNOMIN, because:
- MSC's 'Fznom' matches the unprimed Fz0 it prints in (52), (86) and (87);
- it agrees with MFEVAL, which was tuned to TNO.

Choice raw gamma, because MSC uses raw gamma throughout and no implementation applies LGAZ to s.

Confidence low-medium. N only matters when LFZO != 1 (Q-02).

### 5.2 alpha_eq (D-05)

[derived] With Et fixed (pure alpha_t, D-24), t(x) = Dt cos[Ct atan{Bt x - Et(Bt x - atan(Bt x))}] cos(alpha) is even in x, and Mzr(x) is even too. So where the sign goes does not affect outputs except at 0 (conventions.md section 7). At kappa = 0 and |at| < pi/2, ate = at exactly, so combined Mz reduces to Mz0 + s*Fx.

Which Kx and Ky enter: MSC prints unsubscripted K_x/K_y (p.32). K_y is the symbol of (38), not K_y0 of (37). MFEVAL Kxk/Kya' (:1581, Kya' at :1145), OPENTIRE K_x (25) and K_y (38) (:383, :386), and CHRONO Kx/Ky all agree.

### 5.3 F'y and pure Mz0 (D-16)

- MSC p.23 prints Mz0 = -t*Fy0 + Mzr, with M'z = Mz0(alpha, gamma, Fz) (43). Fy0 carries no gamma = 0 mark.
- (81) prints the LHS as F'_y,gamma=0 but the RHS as Fy - S_Vyk.
- **Reading (A):** F'y = Fy - SVyk at the actual gamma. Consistency rule [derived]: at kappa = 0, Gyk = 1 and SVyk = 0, so (A) gives combined Mz = Mz0 + s*Fx with Mz0 as printed. **Reading (B)** (gamma = 0) breaks this identity.
- (A) also matches OPENTIRE :420, CHRONO :318 and CHRONO8 :1230. (B) is the MF 6.1 book/paper form (TEASIT; MFEVAL MF 6.1 branch :1613).
- Rev 3 recommended (B). It is reversed here because the printed pure-slip equation forces (A) (rev-2 vector V17). Confidence: medium.

### 5.4 Friction ellipse (D-06, D-08)

Printed (MSC p.33-34):
- kappa_c = kappa + SHx + SVx/Kx; alpha_c = alpha + SHy + SVy/Ky; alpha* = sin(alpha_c).
- beta = acos(|kappa_c|/sqrt(kappa_c^2 + alpha*^2)).
- mu_x,act = (Fx0 - SVx)/Fz; mu_y,act = (Fy0 - SVy)/Fz; mu_x,max = Dx/Fz; mu_y,max = Dy/Fz.
- mu_x = 1/sqrt((1/mu_x,act)^2 + (tan beta/mu_y,max)^2); mu_y = tan beta/sqrt((1/mu_x,max)^2 + (tan beta/mu_y,act)^2).
- Fx = (mu_x/mu_x,act)*Fx0; Fy = (mu_y/mu_y,act)*Fy0.
- p.33 calls the method 'an in-house development of MSC.Software'.

Defect [derived]: mu_x and mu_y are always >= 0, so the printed ratio flips the sign of a force whenever its mu_act < 0. Implement the form below, which is identical to the printed one with |mu_act| (CHRONO :262-263 does the same):

```
mxa = |Fx0 - SVx|/Fz ; mya = |Fy0 - SVy|/Fz ; mxm = |Dx|/Fz ; mym = |Dy|/Fz
rx = |kc|*mym / sqrt(kc^2*mym^2 + mxa^2*as^2)
ry = |as|*mxm / sqrt(kc^2*mya^2 + as^2*mxm^2)        (as = alpha*)
Fx = rx*Fx0 ; Fy = ry*Fy0 ; a 0/0 ratio gives r = 1 [policy]
```

Moments: 'the formulae (76) until and including (85) are used with S_Vyk = 0' (p.34). So Mz = -t(ate)*Fy + Mzr(are) + s*Fx, with F'y = Fy. CHRONO's ellipse Mz (no s*Fx, pure t) deviates from this.

### 5.5 Combined-method selection (D-07)

MSC p.33: 'In case the tire property file does not contain the coefficients for the standard combined slip method (cosine weighing functions), the friction ellipse method is used.'

Let R = {RBX1, RBX2, RCX1, REX1, REX2, RHX1, RBY1, RBY2, RBY3, RCY1, REY1, REY2, RHY1, RHY2, RVY1..RVY6}.
- All present (a zero value counts as present): cosine method.
- None present: friction ellipse.
- Partial set: load error naming the missing keys. This keeps the rev-2 rule. Rev-3's 'cosine with zeros' is rejected because RBX1 = 0 silently disables the combined reduction (Gxa = 1).

FE_METHOD (a CHRONO-only key, :635-644) is not an MSC key: warn and ignore it (Q-06).

### 5.6 Normalisations (D-23)

- As printed: F'z0 in (16) and (37); Fz0 (= FNOMIN) in (52), (86) and (87). Re-verified on p.23 and p.32: no primes.
- CHRONO uses F'z0 in Dt and Mx.
- Keep the printed forms. MFEVAL's MF 5.2 trail (R0/F'z0 times LFZO) equals R0/FNOMIN [derived], which supports them.

## 7. CHRONO (39393e3) defects: do not use as a reference

- gamma is never set from the wheel (:1748, 1815, 1824).
- PDX3 is never read from .tir.
- The pressure flag is always false, which zeroes PPX*, PPY*, QSY1, QSY2, QSY8 and QPFZ1 for every .tir (:1430-1440, 389-403).
- Ky lacks LKY and adds LKYG; mu_y has the '+' sign.
- The ellipse Mz omits s*Fx; alpha_teq is multiplied by sgn(kappa).
- eps = 0.1; argument clamps.
- FITTYP is ignored; USE_MODE 14 gives zero forces.
- The KN and KPOUND unit factors are inverted.
- Mx and My are MF 6.1-style.

CHRONO8 also multiplies Ky by LYKA (:1066-1068), another defect [impl].
