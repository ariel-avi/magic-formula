# PAC2002: equations and rules

## 1. Scope

- Steady state only. Transient (relaxation) behaviour is out of scope.
- Turn slip is neglected: all turn-slip factors zeta_0..zeta_8 = 1, so C_r = zeta_7 = 1.

## 2. Evaluation order (authoritative)

```
 0  load: FNOMIN and UNLOADED_RADIUS > 0, LFZO > 0, kernel-critical keys present
    (tir-format.md section 3); choose the combined method (section 5.5)
 1  Fz <= 0 -> all outputs 0                                conventions.md section 8
 2  clamp Fz, kappa, alpha, gamma to [*_RANGE]              conventions.md section 8
 3  F'z0, dfz                                               load normalisation (section 3)
 4  Fx0                                                     pure Fx0
 5  Fy0, Ky                                                 pure Fy0
 6  pure t(alpha_t), Mzr(alpha_r); Mz0 = -t*Fy0 + Mzr       pure Mz0
 7  combined Fx, Fy: cosine method or friction ellipse (section 5.4)
 8  combined Mz; sections 5.1-5.3
 9  Mx; My (QSY form, or SHIFTS form)                       conventions.md section 4
10  Mz_gyr = 0: the gyroscopic term contains a time derivative, zero in steady state;
    output sign mapping (conventions.md section 4)
Uncombined mode (conventions.md section 10): Fx = Fx0, Fy = Fy0, Mz = Mz0; Mx and My use these forces.
```

## 3. Equations

gamma is the raw input. Epsilon guards per conventions.md section 7.

```
-- load normalisation
F'z0 = FNOMIN*LFZO ; dfz = (Fz - F'z0)/F'z0
-- pure Fx0
kx  = kappa + SHx
gx  = gamma*LGAX
Cx  = PCX1*LCX
Dx  = mux*Fz
mux = (PDX1 + PDX2*dfz)*(1 - PDX3*gx^2)*LMUX                          see section 4
Ex  = (PEX1 + PEX2*dfz + PEX3*dfz^2)*(1 - PEX4*sgn(kx))*LEX, Ex <= 1
Kx  = Fz*(PKX1 + PKX2*dfz)*exp(PKX3*dfz)*LKX
Bx  = Kx/(Cx*Dx + eps)
SHx = (PHX1 + PHX2*dfz)*LHX
SVx = Fz*(PVX1 + PVX2*dfz)*LVX*LMUX
Fx0 = Dx*sin[Cx*atan{Bx*kx - Ex*(Bx*kx - atan(Bx*kx))}] + SVx         SVx outside the sine, see section 4
-- pure Fy0
ay  = alpha + SHy
gy  = gamma*LGAY
Cy  = PCY1*LCY
Dy  = muy*Fz
muy = (PDY1 + PDY2*dfz)*(1 - PDY3*gy^2)*LMUY
Ey  = (PEY1 + PEY2*dfz)*(1 - (PEY3 + PEY4*gy)*sgn(ay))*LEY, Ey <= 1  see section 4
Ky0 = PKY1*FNOMIN*sin(2*atan(Fz/(PKY2*FNOMIN*LFZO)))*LFZO*LKY
    = PKY1*F'z0*sin(2*atan(Fz/(PKY2*F'z0)))*LKY
Ky  = Ky0*(1 - PKY3*|gy|)
By  = Ky/(Cy*Dy + eps)
SHy = (PHY1 + PHY2*dfz)*LHY + PHY3*gy
SVy = Fz*((PVY1 + PVY2*dfz)*LVY + (PVY3 + PVY4*dfz)*gy)*LMUY
Fy0 = Dy*sin[Cy*atan{By*ay - Ey*(By*ay - atan(By*ay))}] + SVy
-- pure Mz0
Mz0 = -t*Fy0 + Mzr                 Fy0 at the actual gamma (section 5.3)
t   = Dt*cos[Ct*atan{Bt*at - Et*(Bt*at - atan(Bt*at))}]*cos(alpha)
at  = alpha + SHt
Mzr = Dr*cos[Cr*atan(Br*ar)]*cos(alpha)
ar  = alpha + SHf
SHf = SHy + SVy/(Ky + eps)
gz  = gamma*LGAZ
Bt  = (QBZ1 + QBZ2*dfz + QBZ3*dfz^2)*(1 + QBZ4*gz + QBZ5*|gz|)*LKY/LMUY
Ct  = QCZ1
Dt  = Fz*(QDZ1 + QDZ2*dfz)*(1 + QDZ3*gz + QDZ4*gz^2)*(R0/FNOMIN)*LTR  section 5.6
Et  = (QEZ1 + QEZ2*dfz + QEZ3*dfz^2)*(1 + (QEZ4 + QEZ5*gz)*(2/pi)*atan(Bt*Ct*at)), Et <= 1
SHt = QHZ1 + QHZ2*dfz + (QHZ3 + QHZ4*dfz)*gz
Br  = QBZ9*LKY/LMUY + QBZ10*By*Cy
Cr  = zeta_7 = 1                                                      section 1
Dr  = Fz*((QDZ6 + QDZ7*dfz)*LRES + (QDZ8 + QDZ9*dfz)*gz)*R0*LMUY      see section 4
Kz = -t*Ky (aligning stiffness) is not an output.
-- combined Fx (cosine method)
Fx   = Fx0*Gxa
Gxa  = cos[Cxa*atan{Bxa*as - Exa*(Bxa*as - atan(Bxa*as))}]
     / cos[Cxa*atan{Bxa*SHxa - Exa*(Bxa*SHxa - atan(Bxa*SHxa))}]
as   = alpha + SHxa
Bxa  = RBX1*cos(atan(RBX2*kappa))*LXAL
Cxa  = RCX1 ; Exa = REX1 + REX2*dfz (Exa <= 1) ; SHxa = RHX1
-- combined Fy (cosine method)
Fy   = Fy0*Gyk + SVyk
Gyk  = form of Gxa with Byk, Cyk, Eyk, ks, SHyk
ks   = kappa + SHyk
Byk  = RBY1*cos(atan(RBY2*(alpha - RBY3)))*LYKA
Cyk  = RCY1 ; Eyk = REY1 + REY2*dfz (Eyk <= 1) ; SHyk = RHY1 + RHY2*dfz
SVyk = DVyk*sin(RVY5*atan(RVY6*kappa))*LVYKA
DVyk = muy*Fz*(RVY1 + RVY2*dfz + RVY3*gamma)*cos(atan(RVY4*alpha))
-- combined Mz
Mz  = -t*F'y + Mzr + s*Fx                                            (Mz_gyr = 0, step 10)
t   = Dt*cos[Ct*atan{Bt*ate - Et*(Bt*ate - atan(Bt*ate))}]*cos(alpha)
F'y = Fy - SVyk                                                       actual-camber reading (section 5.3)
Mzr = Dr*cos[Cr*atan(Br*are)]*cos(alpha)                              with Cr (section 4)
ate = atan(sqrt(tan^2(at) + (Kx/Ky)^2*kappa^2))*sgn+(at)              alpha_eq, section 5.2
are = atan(sqrt(tan^2(ar) + (Kx/Ky)^2*kappa^2))*sgn+(ar)              alpha_eq, section 5.2
s   = R0*(SSZ1 + SSZ2*Fy/FNOMIN + (SSZ3 + SSZ4*dfz)*gamma)*LS        section 5.1
-- moments
Mx  = R0*Fz*(QSX1*LVMX - QSX2*gamma + QSX3*Fy/FNOMIN)*LMX
My, QSY form:
My  = R0*Fz*(QSY1 + QSY2*Fx/FNOMIN + QSY3*|Vx/LONGVL| + QSY4*(Vx/LONGVL)^4)*LMY  see section 4
My, SHIFTS form (iff FITTYP = 5 and QSY1 = QSY2 = 0; model-routing.md):
My  = R0*(SVx + Kx*SHx)
Output My_out = -My (conventions.md section 4).
```

In ate and are, Kx is the Kx of the pure Fx0 block and Ky the Ky of the pure Fy0 block (with the camber reduction, not Ky0). In Mz, Mx, My and s, Fx and Fy are the outputs of the active combined method.

## 4. Equation choices

| Item | Choice | Reason |
|---|---|---|
| Magic Formula form | sine form for the forces Fx0 and Fy0; cosine form for t and Mzr | a force rises to a peak and saturates with slip (sine of an arctangent); the trail and the residual moment are largest at zero slip and decay with slip (cosine of an arctangent) |
| SVx placement | SVx is added outside the sine in Fx0 | SVx is a vertical shift of the curve (Y = y(x) + SV), placed like SVy in Fy0; inside the sine it would change the curve's shape instead of shifting it. V4 pins it (40 N, against 2980.45 N with SVx inside) |
| Camber in mu_x | mu_x uses gamma_x = gamma*LGAX | gamma_x is the scaled camber of the longitudinal equations, which makes LGAX the camber scale factor of Fx; with LGAX = 1 it equals the raw-gamma MF 5.2 form. V16 pins it; open item (open-questions.md) |
| Cr in combined Mzr | the combined Mzr carries Cr (= 1), like the pure Mzr | same form in pure and combined slip; with turn slip neglected Cr = 1, so the value is unchanged |
| Sign in alpha_eq | sgn+(a) multiplies the arctangent, outside the square root | a sign factor inside the root can make the radicand negative; outside it, alpha_eq has the sign of a and the radicand tan^2(a) + (Kx/Ky)^2*kappa^2 stays >= 0 (section 5.2) |
| My Fx term | QSY2 multiplies Fx/FNOMIN | each QSY coefficient has one role: QSY1 constant, QSY2 Fx dependence, QSY3 \|Vx/LONGVL\|, QSY4 (Vx/LONGVL)^4 |
| My scaling | the QSY form is multiplied by LMY | LMY is the user scale factor of My (default 1), as LMX is for Mx |
| Ey scaling | Ey is multiplied by LEY | LEY is the curvature scale factor of Ey, as LEX is for Ex |
| Dr scaling | LRES on the (QDZ6 + QDZ7*dfz) term, LMUY on the whole Dr | LRES scales the residual moment; LMUY scales Dr with the lateral friction, as it scales Dy |
| E limit | Ex, Ey, Et, Exa and Eyk are clamped to <= 1 | for E > 1 the argument B*x - E*(B*x - atan(B*x)) has slope B*(1 - E) < 0 at large B*x, so the curve folds back; E <= 1 keeps the argument monotonic. V15 pins the clamp |

## 5. Details

### 5.1 Moment arm s

- s is the moment arm of Fx in the combined aligning moment: s = R0*(SSZ1 + SSZ2*Fy/FNOMIN + (SSZ3 + SSZ4*dfz)*gamma)*LS, with Fy the combined output and gamma raw.
- Coefficient meanings: SSZ1 = nominal s/R0 (effect of Fx on Mz); SSZ2 = variation of s/R0 with Fy/FNOMIN; SSZ3 = variation with inclination; SSZ4 = variation with load and inclination; LS = scale factor of the moment arm of Fx.
- Normaliser FNOMIN (not F'z0): the moment terms Dt, Mx and My all use the unprimed FNOMIN (section 5.6), and s follows them. Raw gamma: no camber scale factor applies to s, as in Mx.
- The normaliser matters only when LFZO != 1 (open item, open-questions.md).

### 5.2 alpha_eq

With Et fixed (pure alpha_t), t(x) = Dt cos[Ct atan{Bt x - Et(Bt x - atan(Bt x))}] cos(alpha) is even in x, and Mzr(x) is even too. So where the sign goes does not affect outputs except at 0 (conventions.md section 7). At kappa = 0 and |at| < pi/2, ate = at exactly, so combined Mz reduces to Mz0 + s*Fx.

Kx is the Kx of the pure Fx0 block; Ky is the Ky of the pure Fy0 block, including the camber reduction (1 - PKY3*|gy|), not Ky0.

### 5.3 F'y and pure Mz0

- The pure aligning moment is Mz0 = -t*Fy0 + Mzr, with Fy0 at the actual gamma.
- In combined slip, F'y = Fy - SVyk.
- **Actual-camber reading:** F'y = Fy - SVyk at the actual gamma. At kappa = 0, Gyk = 1 and SVyk = 0, so combined Mz = Mz0 + s*Fx with Mz0 as above. The **zero-camber reading** (F'y evaluated at gamma = 0) breaks this identity and is not used for PAC2002. MF 5.2 uses a mixed form (mf52.md section 4, step 8).
- Implemented: the actual-camber reading (vector V17; property test P3).

### 5.4 Friction ellipse

Definition (mu form), with Kx and Ky eps-guarded (conventions.md section 7):
- kappa_c = kappa + SHx + SVx/Kx; alpha_c = alpha + SHy + SVy/Ky; alpha* = sin(alpha_c).
- beta = acos(|kappa_c|/sqrt(kappa_c^2 + alpha*^2)).
- mu_x,act = |Fx0 - SVx|/Fz; mu_y,act = |Fy0 - SVy|/Fz; mu_x,max = |Dx|/Fz; mu_y,max = |Dy|/Fz.
- mu_x = 1/sqrt((1/mu_x,act)^2 + (tan beta/mu_y,max)^2); mu_y = tan beta/sqrt((1/mu_x,max)^2 + (tan beta/mu_y,act)^2).
- Fx = (mu_x/mu_x,act)*Fx0; Fy = (mu_y/mu_y,act)*Fy0.

Why magnitudes: mu_x and mu_y are >= 0 by construction, so a ratio with a signed mu_act would flip the sign of a force whenever mu_act < 0. With magnitudes each ratio lies in [0, 1] and each force keeps the sign of its pure-slip value (P1).

Implemented (ratio form, algebraically identical and free of Fz; P2 checks the identity):

```
mxa = |Fx0 - SVx|/Fz ; mya = |Fy0 - SVy|/Fz ; mxm = |Dx|/Fz ; mym = |Dy|/Fz
rx = |kc|*mym / sqrt(kc^2*mym^2 + mxa^2*as^2)
ry = |as|*mxm / sqrt(kc^2*mya^2 + as^2*mxm^2)        (as = alpha*)
Fx = rx*Fx0 ; Fy = ry*Fy0 ; a 0/0 ratio gives r = 1 (policies.md section 2)
```

Moments: the combined Mz equations are used with SVyk = 0, so Mz = -t(ate)*Fy + Mzr(are) + s*Fx with F'y = Fy.

### 5.5 Combined-method selection

The cosine method needs its weighting coefficients R = {RBX1, RBX2, RCX1, REX1, REX2, RHX1, RBY1, RBY2, RBY3, RCY1, REY1, REY2, RHY1, RHY2, RVY1..RVY6}.
- All present (a zero value counts as present): cosine method.
- None present: friction ellipse, which needs no extra coefficients, with a warning.
- Partial set: load error naming the missing keys. 'Cosine with zeros' is rejected because RBX1 = 0 silently disables the combined reduction (Gxa = 1).

FE_METHOD is not a key of this formulation: it gives a warning and is ignored (open item, open-questions.md).

### 5.6 Normalisations

- F'z0 = FNOMIN*LFZO in the load normalisation (dfz) and in Ky0; the unprimed FNOMIN in Dt, Mx and My (and in s, section 5.1).
- MF 5.2 writes the trail with R0/F'z0 and multiplies t by LFZO. Because F'z0 = FNOMIN*LFZO, this equals R0/FNOMIN, so both models use the same trail normaliser.
