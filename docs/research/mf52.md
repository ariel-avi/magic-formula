# MF 5.2 (FITTYP = 6)

## 1. Status and settings

- MF 5.2 is identified by FITTYP = 6 (section 2). Its parameter set is section 3. Its evaluation order and equations (section 4) are the project's definition and are authoritative.
- Each MF 5.2 form equals the PAC2002 form named next to it (pac2002.md section 3), except the differences in pac2002-vs-mf52.md.
- Settings fixed by this definition:
  - raw inputs: alpha* = alpha and gamma* = gamma (no tan or sin substitution);
  - turn slip neglected: all zeta = 1;
  - friction scaling uses LMUX and LMUY directly (no speed-dependent friction scaling);
  - range clamping and the E <= 1 limits always apply; no low-speed model (section 5).

## 2. Identification

FITTYP = 6 identifies MF 5.2 (model-routing.md). MF 5.2 has no temperature and velocity extension and no pressure input (conventions.md section 11).

## 4. Evaluation order and equations (authoritative)

Inputs: Fz, kappa, alpha, gamma (raw), Vx > 0 (conventions.md section 5). Steps 0-2 are as in PAC2002 (conventions.md section 8).

```
3 Fz0 = FNOMIN ; F'z0 = LFZO*Fz0 ; dfz = (Fz - F'z0)/F'z0
  Vsy = tan(alpha)*Vx ; Vc = sqrt(Vx^2 + Vsy^2) ; cosp = Vx/(Vc + eps)
4 Fx0
  Cx = PCX1*LCX ; mux = (PDX1 + PDX2*dfz)*(1 - PDX3*gamma^2)*LMUX ; Dx = mux*Fz
  Kx = Fz*(PKX1 + PKX2*dfz)*exp(PKX3*dfz)*LKX ; Bx = Kx/(Cx*Dx + eps*sgn+(Cx*Dx))
  SHx = (PHX1 + PHX2*dfz)*LHX ; SVx = Fz*(PVX1 + PVX2*dfz)*LVX*LMUX ; kx = kappa + SHx
  Ex = (PEX1 + PEX2*dfz + PEX3*dfz^2)*(1 - PEX4*sgn(kx))*LEX, Ex <= 1
  Fx0 = Dx*sin(Cx*atan(Bx*kx - Ex*(Bx*kx - atan(Bx*kx)))) + SVx
  = the PAC2002 pure Fx0 block (pac2002.md section 3) with raw gamma in mu_x (no LGAX)
5 Fy0
  Ky  = PKY1*F'z0*(1 - PKY3*|gamma|)*sin(2*atan(Fz/(PKY2*F'z0)))*LKY      (the factor 2 is a constant: MF 5.2 has no PKY4 or PKY5)
  SHy = (PHY1 + PHY2*dfz)*LHY + PHY3*gamma
  SVy = Fz*((PVY1 + PVY2*dfz)*LVY + (PVY3 + PVY4*dfz)*gamma)*LMUY
  muy = (PDY1 + PDY2*dfz)*(1 - PDY3*gamma^2)*LMUY ; Dy = muy*Fz ; Cy = PCY1*LCY
  ay  = alpha + SHy ; Ey = (PEY1 + PEY2*dfz)*(1 - (PEY3 + PEY4*gamma)*sgn+(ay))*LEY, Ey <= 1
  By  = Ky/(Cy*Dy + eps*sgn+(Cy*Dy)) ; Fy0 = Dy*sin(Cy*atan(By*ay - Ey*(By*ay - atan(By*ay)))) + SVy
  = the PAC2002 pure Fy0 block with gamma_y replaced by raw gamma
6 aligning terms (PAC2002 pure Mz0 forms with raw gamma; Dt and Dr differ, see notes and pac2002-vs-mf52.md)
  Ky' = Ky + eps*sgn+(Ky)
  SHt = QHZ1 + QHZ2*dfz + (QHZ3 + QHZ4*dfz)*gamma ; at = alpha + SHt
  SHf = SHy + SVy/Ky' ; ar = alpha + SHf                                   (SHf as in the PAC2002 pure Mz0 block)
  Bt = (QBZ1 + QBZ2*dfz + QBZ3*dfz^2)*(1 + QBZ4*gamma + QBZ5*|gamma|)*LKY/LMUY
  Ct = QCZ1
  Dt = Fz*(QDZ1 + QDZ2*dfz)*(1 + QDZ3*gamma + QDZ4*gamma^2)*(R0/F'z0)*LTR  (QDZ3 on signed gamma)
  Et = (QEZ1 + QEZ2*dfz + QEZ3*dfz^2)*(1 + (QEZ4 + QEZ5*gamma)*(2/pi)*atan(Bt*Ct*at)), Et <= 1
  Br = QBZ9*LKY/LMUY + QBZ10*By*Cy ; Cr = 1
  Dr = Fz*R0*((QDZ6 + QDZ7*dfz)*LRES + (QDZ8 + QDZ9*dfz)*gamma)*LMUY*cos(alpha)
7 combined forces (same as PAC2002)
  Fx = Fx0*Gxa, with Gxa as in the PAC2002 combined Fx block (RBX3 = 0)
  Fy = Fy0*Gyk + SVyk as in the PAC2002 combined Fy block (RBY4 = 0);
  DVyk = muy*Fz*(RVY1 + RVY2*dfz + RVY3*gamma)*cos(atan(RVY4*alpha))
8 combined Mz (MF 5.2 form)
  ate, are: the alpha_eq equations of pac2002.md section 3 with Kx/Ky' and sgn+ (pac2002.md section 5.2)
  t   = Dt*cos(Ct*atan(Bt*ate - Et*(Bt*ate - atan(Bt*ate))))*cosp*LFZO
  Mzr = Dr*cos(Cr*atan(Br*are))                                            (no further cos factor: cos(alpha) is inside Dr)
  s   = R0*(SSZ1 + SSZ2*Fy/Fz0 + (SSZ3 + SSZ4*dfz)*gamma)*LS
  SVyk0 = SVyk recomputed with muy evaluated at gamma = 0 (all other terms at the actual gamma)
  Mz  = -t*(Fy - SVyk0) + Mzr + s*Fx
9 Mx = R0*Fz*(QSX1*LVMX - QSX2*gamma + QSX3*Fy/Fz0)*LMX                    (MF 5.2 has no QSX4-QSX14)
  My = -R0*Fz*(QSY1 + QSY2*Fx/Fz0 + QSY3*|Vx/LONGVL| + QSY4*(Vx/LONGVL)^4)*LMY
  (the sign of My is final; do not flip it again)
Uncombined (conventions.md section 10; policies.md section 1): Fx = Fx0, Fy = Fy0, Mz0 = -t(at)*Fy0 + Mzr(ar), using the step-8 forms of t (cosp, LFZO) and Mzr.
```

Notes:
- Dt*LFZO in t equals Fz*(...)*(R0/FNOMIN), the PAC2002 Dt.
- At kappa = 0: SVyk = SVyk0 = 0 and Gyk = 1, so Mz = -t(at)*Fy0 + Mzr(ar) + s*Fx. This is the same identity as for PAC2002 (test P3).
- The uncombined Mz0 uses Fy0 at the actual camber and applies the cos(alpha) factor of Mzr once (inside Dr).

## 5. Behaviours not adopted

| Behaviour | Alternative considered | Here | Why |
|---|---|---|---|
| 0 < Fz < FZMIN | Fz not raised; low-load factors Fz*(Fz/FZMIN)^2 in Mx and Fz*(Fz/FZMIN) in My | Fz clamped to FZMIN | the clamping rule evaluates every MF input at its range limit (conventions.md section 8) |
| Low speed | active only with limit checks on and \|Vx\| <= VXLOW (equality included); with w = 0.5*(1 + cos(pi*Vx/VXLOW)): SVx, SHx, SVyk, t and Mzr scaled by (1 - w); kappa by \|Vx/VXLOW\|; alpha by (\|Vx\| + \|Vsy\|)/VXLOW | none | VXLOW is not applied (conventions.md section 5; policies.md section 1) |
| Low-speed My taper | with highLimit = VXLOW/\|Vx\| - 1 and lowLimit = -1 - VXLOW - highLimit, acting on the unclamped kappa: My *= sin(pi/2*(kappa+1)/(highLimit+1)) for lowLimit <= kappa <= highLimit, and My = -My for kappa < lowLimit; My = 0 at kappa = -1 (wheel lock) | none: step 9 as written | no low-speed law is adopted (conventions.md section 5; policies.md section 1); the rule is empirical, lies outside the equations of section 4, and lowLimit adds VXLOW [m/s] to a dimensionless slip. Open item (open-questions.md); validation.md section 5, low-speed My taper |
| Vx = 0 | slip-angle term, My and cosp set to 0 | row rejected | conventions.md section 5 |
| Warnings | a warning on every evaluation | one warning per variable for the run | conventions.md section 8; policies.md section 1 |
| E and Fz clamps | only in a limit-checking mode | always | the E limit keeps the curve monotonic (pac2002.md section 4); range clamping per conventions.md section 8 |
| alpha_eq at exactly 0 | sgn(0) = 0 | sgn+ | continuity of Mz (conventions.md section 7) |
| Mx | extended Mx form with QSX4-QSX14 | Mx equation | those coefficients are not MF 5.2 parameters, so the form reduces to the PAC2002 Mx equation |

## 6. Validation status

The equations of section 4 are checked against the committed reference outputs (`tests/data/reference/mf52_mfeval.csv`, `tests/module/mfeval_reference_test.cpp`) and in validation.md. Items that could still change them are in open-questions.md.

## 7. Implementation guidance

Share the kernels with PAC2002. Strategy points:
- camber scaling (PAC2002: LGA*; MF 5.2: none);
- trail factor (cos vs cosp; LFZO);
- F'y (SVyk vs SVyk0);
- My (the SHIFTS form of My is PAC2002 only; the sign is applied inside the MF 5.2 kernel);
- combined fallback (friction ellipse is PAC2002 only);
- parameter-validation sets (section 3).

Tests: test-data.md, M-vectors.
