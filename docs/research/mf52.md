# MF 5.2 (TNO MF-Tyre 5.2, FITTYP = 6)

Revision 4.

## 1. Status and evidence tier

- Identification, acceptance and the parameter set are **primary** (SIM20).
- The equations are **[impl] only**. The source is MFEVAL 4.0.0 `+mfeval/Solver.m`:
  - its FITTYP == 6 branches are commented 'MF5.2 equations from the MF-Tyre equation manual' (:938, 1021, 1508, 1634);
  - its deviations from the Pacejka book were tuned to match TNO (`doc/changesEquations.html`). The TNO version named there is 6.1.2.1, for 6.1 only. No TNO version is named for 5.2 validation;
  - MF 5.2 support was added in MFeval 4.0.0 (releaseNotes, 17-03-2020).
- No primary MF 5.2 equation text is available: SIM20 has none, TNO62, TNO61 and BSP10 are blocked, and MF52-EQM is excluded.
- Repo rule 4: the user accepted the [impl] tier for section 4 (AD-26 in decisions.md; Q-01 closed). Each form below is cross-referenced to the MSC PAC2002 equation it equals.
- MFEVAL settings reproduced here:
  - useMode tens digit 1: alpha* = alpha and gamma* = gamma. The source says 'TNO MF-Tyre does not use this' (Solver.m:667-675; changesEquations Sec. 1).
  - Units digit 1: no turn slip, all zeta = 1.
  - Amu = 1 (:692) and LMUV = 0 (:631), so LMUX* = LMUX' = LMUX and LMUY* = LMUY' = LMUY.
  - Limit-check behaviour (hundreds digit 1) is reproduced only where it matches the primaries (clamping, E <= 1). The low-speed model is not reproduced, including the My kappa band (Solver.m:1517-1537).

## 4. Evaluation order and equations (authoritative; [impl], MFEVAL Solver.m line numbers)

Inputs: Fz, kappa, alpha, gamma (raw), Vx > 0 (D-27). Steps 0-2 are as in PAC2002 (D-03, D-04).

```
3 Fz0 = FNOMIN ; F'z0 = LFZO*Fz0 ; dfz = (Fz - F'z0)/F'z0                 :623, :659, :662
  Vsy = tan(alpha)*Vx ; Vc = sqrt(Vx^2 + Vsy^2) ; cosp = Vx/(Vc + eps)    :647-682
4 Fx0                                                                      :782-819
  Cx = PCX1*LCX ; mux = (PDX1 + PDX2*dfz)*(1 - PDX3*gamma^2)*LMUX ; Dx = mux*Fz
  Kx = Fz*(PKX1 + PKX2*dfz)*exp(PKX3*dfz)*LKX ; Bx = Kx/(Cx*Dx + eps*sgn+(Dx))
  SHx = (PHX1 + PHX2*dfz)*LHX ; SVx = Fz*(PVX1 + PVX2*dfz)*LVX*LMUX ; kx = kappa + SHx
  Ex = (PEX1 + PEX2*dfz + PEX3*dfz^2)*(1 - PEX4*sgn(kx))*LEX, Ex <= 1
  Fx0 = Dx*sin(Cx*atan(Bx*kx - Ex*(Bx*kx - atan(Bx*kx)))) + SVx
  = MSC (18)-(28) with C2, except raw gamma (no LGAX)
5 Fy0                                                                      :930-1056
  Ky  = PKY1*F'z0*(1 - PKY3*|gamma|)*sin(2*atan(Fz/(PKY2*F'z0)))*LKY      :930 with PKY4 = 2, PKY5 = 0
  SHy = (PHY1 + PHY2*dfz)*LHY + PHY3*gamma                                :1021 with LKYC = 1
  SVy = Fz*((PVY1 + PVY2*dfz)*LVY + (PVY3 + PVY4*dfz)*gamma)*LMUY         :931, :1026
  muy = (PDY1 + PDY2*dfz)*(1 - PDY3*gamma^2)*LMUY ; Dy = muy*Fz ; Cy = PCY1*LCY   :1036-1038
  ay  = alpha + SHy ; Ey = (PEY1 + PEY2*dfz)*(1 - (PEY3 + PEY4*gamma)*sgn+(ay))*LEY, Ey <= 1   :1035-1049
  By  = Ky/(Cy*Dy + eps*sgn+(Dy)) ; Fy0 = Dy*sin(Cy*atan(By*ay - Ey*(By*ay - atan(By*ay)))) + SVy   :1051-1056
  = MSC (30)-(41) with gamma_y -> gamma
6 aligning terms (calculateMz0 has no FITTYP branch)                       :1140-1265
  Ky' = Ky + eps*sgn+(Ky)                                                  :1142-1145
  SHt = QHZ1 + QHZ2*dfz + (QHZ3 + QHZ4*dfz)*gamma ; at = alpha + SHt       :1140, :1148
  SHf = SHy + SVy/Ky' ; ar = alpha + SHf                                   MSC (48) form (Q-19)
  Bt = (QBZ1 + QBZ2*dfz + QBZ3*dfz^2)*(1 + QBZ4*gamma + QBZ5*|gamma|)*LKY/LMUY   :1188 (A58)
  Ct = QCZ1                                                                :1189
  Dt = Fz*(QDZ1 + QDZ2*dfz)*(1 + QDZ3*gamma + QDZ4*gamma^2)*(R0/F'z0)*LTR  :1177 (A60; QDZ3 on signed gamma)
  Et = (QEZ1 + QEZ2*dfz + QEZ3*dfz^2)*(1 + (QEZ4 + QEZ5*gamma)*(2/pi)*atan(Bt*Ct*at)), Et <= 1   :1190-1198
  Br = QBZ9*LKY/LMUY + QBZ10*By*Cy ; Cr = 1                                :1264-1265
  Dr = Fz*R0*((QDZ6 + QDZ7*dfz)*LRES + (QDZ8 + QDZ9*dfz)*gamma)*LMUY*cos(alpha)   :1263 (sgn(Vx) = 1)
7 combined forces (no FITTYP branch)                                       :1295-1386
  Fx = Fx0*Gxa, Gxa per MSC (60)-(66) with RBX3 = 0
  Fy = Fy0*Gyk + SVyk per MSC (67)-(77) with RBY4 = 0;
  DVyk = muy*Fz*(RVY1 + RVY2*dfz + RVY3*gamma)*cos(atan(RVY4*alpha))
8 combined Mz (FITTYP 6 branch)                                            :1581-1634
  ate, are: MSC (84)-(85) repaired, Kx/Ky', sign per D-05 (MFEVAL uses sign(0) = 0)
  t   = Dt*cos(Ct*atan(Bt*ate - Et*(Bt*ate - atan(Bt*ate))))*cosp*LFZO     :1614-1616
  Mzr = Dr*cos(Cr*atan(Br*are))                                            :1584 (no second cos)
  s   = R0*(SSZ1 + SSZ2*Fy/Fz0 + (SSZ3 + SSZ4*dfz)*gamma)*LS               :1583
  SVyk0 = SVyk recomputed with muy evaluated at gamma = 0 (all other terms at the actual gamma)   :1587-1611
  Mz  = -t*(Fy - SVyk0) + Mzr + s*Fx                                       :1632-1634
9 Mx = R0*Fz*(QSX1*LVMX - QSX2*gamma + QSX3*Fy/Fz0)*LMX                    :1445-1447 (QSX4-14 = PPMX1 = 0)
  My = -R0*Fz*(QSY1 + QSY2*Fx/Fz0 + QSY3*|Vx/LONGVL| + QSY4*(Vx/LONGVL)^4)*LMY   :1506-1508
  (the sign of My is final; do not flip it again)
Uncombined (D-26) [policy]: Fx = Fx0, Fy = Fy0, Mz0 = -t(at)*Fy0 + Mzr(ar), using the step-8 forms of t (cosp, LFZO) and Mzr.
```

Notes:
- [derived] Dt*LFZO in t equals Fz*(...)*(R0/Fz0), the same as MSC (52).
- [derived] At kappa = 0: SVyk = SVyk0 = 0 and Gyk = 1, so Mz = -t(at)*Fy0 + Mzr(ar) + s*Fx. This is the same identity as for PAC2002 (test P3).
- MFEVAL discards its own pure Mz0 (doForcesAndMoments :2044). That Mz0 uses Fy0 at gamma = 0 (:1202-1214) and applies cos'(alpha) twice in Mzr0 (:1263, :1266). It is not used here.

## 6. Residual uncertainty ([impl]-only items)

## 7. Implementation guidance

Share the kernels with PAC2002. Strategy points:
- camber scaling (PAC2002: LGA*; MF 5.2: none);
- trail factor (cos vs cosp; LFZO);
- F'y (SVyk vs SVyk0);
- My (the eq-88 path is PAC2002 only; the sign is applied inside the MF 5.2 kernel);
- combined fallback (friction ellipse is PAC2002 only);
- parameter-validation sets (section 3).
